# AX300 Vessel Application Assessment (Beta 0.4.1)

Single-page web app (PWA) for AX300 repower and new-build screening. Runs in the phone browser and can be added to the home screen. All data stays on the device unless the user shares a report.

## Files
index.html, manifest.webmanifest, icon-192.png, icon-512.png, apple-touch-icon.png

## Publish (GitHub Pages)
1. Upload all five files to the root of the repository (not the zip).
2. Settings > Pages > Deploy from a branch > main / (root) > Save.
3. Open https://<account>.github.io/<repo>/ in Safari, then Share > Add to Home Screen.

## Updating
Replace the files, wait 1-2 minutes, delete the old home-screen icon and add it again. Check the version in the header (Beta 0.4.1).
